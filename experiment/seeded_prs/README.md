# Independent reviewer benchmark

Five real draft pull requests provided two controls and three planted defects.
The reviewer used the public issue and the exact PR head. The operator kept
the oracle outside the reviewer context and scored the result after review.

The [reviewer benchmark](../reviewer-results.md) records the five heads, the
control and defect cases, the scoring method, and the posted reviews. Machine
readable verdicts are in [reviewer-results.json](../reviewer-results.json).
